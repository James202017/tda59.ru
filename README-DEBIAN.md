# Мира — помощник по недвижимости

Одностраничный сайт с тёмным премиальным дизайном, интерактивными плавающими примерами вопросов, ИИ-чатом и формой передачи обращения в Telegram.

## Что уже есть
- Адаптивная главная страница и 11 направлений недвижимости.
- Примеры вопросов запускают диалог.
- Чат использует OpenAI API через PHP-серверный endpoint.
- Форма обращения отправляет имя, телефон, город, выбранное время и фрагмент диалога в настроенный Telegram-чат.
- Токены и API-ключ хранятся в `/etc/mira-assistant/config.php`, а не в публичных файлах.
- Политика конфиденциальности — шаблон, который владелец обязан заполнить перед публикацией.

## Требования
Debian, Apache, PHP 8.1+ с расширениями `curl`, `mbstring`, `json`. Нужен OpenAI API key и Telegram bot token/chat ID. API OpenAI оплачивается отдельно; доступ к ChatGPT Plus не включает API-баланс автоматически.

## Установка на Debian с Apache

### 1. Сделайте резервную копию
```bash
sudo apache2ctl -S
sudo cp -a /var/www/html "/var/www/html.backup-$(date +%F-%H%M)"
```
Убедитесь, что DocumentRoot именно `/var/www/html`. Если у вашего домена другой DocumentRoot, замените путь ниже. Не перезаписывайте существующий сайт без резервной копии.

### 2. Установите PHP и нужные расширения
```bash
sudo apt update
sudo apt install php libapache2-mod-php php-curl php-mbstring php-json unzip
sudo systemctl restart apache2
php -v
php -m | grep -E 'curl|mbstring|json'
```

### 3. Распакуйте и скопируйте файлы
Распакуйте архив на компьютере. Через WinSCP по SFTP скопируйте содержимое папки `mira-assistant-site` в `/tmp/mira-assistant-site` на Debian. Затем:
```bash
sudo cp -a /tmp/mira-assistant-site/. /var/www/html/
sudo chown -R www-data:www-data /var/www/html
sudo find /var/www/html -type d -exec chmod 755 {} \;
sudo find /var/www/html -type f -exec chmod 644 {} \;
```
Если в `/var/www/html` есть другие сайты/файлы, копируйте выборочно и не меняйте владельца посторонних данных.

### 4. Создайте конфигурацию секретов вне сайта
```bash
sudo install -d -o root -g www-data -m 750 /etc/mira-assistant
sudo nano /etc/mira-assistant/config.php
```
Вставьте и замените значения на свои:
```php
<?php
return [
  'openai_api_key' => 'ВСТАВЬТЕ_OPENAI_API_KEY',
  'openai_model' => 'gpt-4o-mini',
  'telegram_bot_token' => 'ВСТАВЬТЕ_TELEGRAM_BOT_TOKEN',
  'telegram_chat_id' => 'ВСТАВЬТЕ_CHAT_ID',
];
```
Сохраните файл, затем ограничьте доступ:
```bash
sudo chown root:www-data /etc/mira-assistant/config.php
sudo chmod 640 /etc/mira-assistant/config.php
```
**Не помещайте токены в `app.js`, HTML, публичный Git-репозиторий или скриншоты.** Если токен уже публиковался, перевыпустите его.

### 5. Настройте Telegram
1. Создайте бота через `@BotFather` и скопируйте токен.
2. Создайте отдельную группу/чат для заявок и добавьте бота туда. При необходимости разрешите боту отправлять сообщения.
3. Получите chat ID группы проверенным способом (например, через `getUpdates` после отправки тестового сообщения боту; для групп ID часто отрицательный).
4. Внесите токен и chat ID в конфигурацию.
5. Не публикуйте токен и не передавайте его посторонним.

### 6. Проверьте Apache и сайт
```bash
sudo apache2ctl configtest
sudo systemctl reload apache2
curl -I http://127.0.0.1/
sudo tail -n 60 /var/log/apache2/error.log
```
Откройте домен, обновите страницу через Ctrl+F5 и проверьте чат. Если HTTPS уже настроен, используйте `https://ваш-домен/`.

### 7. Тестирование
- Задайте тестовый вопрос: проверьте, что Мира отвечает, а секретный API-ключ не виден в браузере.
- Пройдите форму с тестовым контактом и проверьте, что сообщение реально пришло в правильный Telegram-чат.
- Попробуйте отправить форму без согласия: отправка должна блокироваться.
- Проверьте логи при ошибке: `sudo tail -n 100 /var/log/apache2/error.log`.
- Не тестируйте на реальных данных клиентов без заполненной политики, проверки правовых оснований и настроек защиты.

## Важные замечания перед запуском
- Интеграции заработают только после настройки действительного OpenAI API key и Telegram bot token/chat ID. В архиве нет ваших секретов и никаких настоящих заявок.
- Уточните модель, доступную вашему API-аккаунту; при необходимости измените `openai_model` в конфигурации.
- Примеры вопросов и ответы ИИ не являются гарантией одобрения ипотеки или юридическим заключением.
- `privacy.html` — только шаблон. До публичного запуска заполните данные оператора, контакт для запросов, сроки хранения и проверьте требования законодательства о персональных данных.
- На продакшене рекомендуется добавить ограничение частоты запросов, CAPTCHA/антиспам, ротацию логов и мониторинг расходов API.
- В текущем варианте история чата хранится только в памяти страницы и отправляется серверу при запросах. Серверный код не сохраняет диалоги в базе данных; заявка отправляется в Telegram только после подтверждения формы.
